# /close-task

Read the task and record what was actually resolved.

Run `npm run search -- close-task <reference> --catalogue=<code> --resolution="<evidence>" --by="<operator>"`. Use `--json` when reading the result for further analysis.

Read CLAUDE.md first. Use the operator’s actual name for --by. Preserve unknowns. Report the result and any unresolved issue. Never send, publish or change a live website.
