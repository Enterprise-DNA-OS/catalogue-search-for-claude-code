# /add-catalogue

Create a catalogue with a named owner and lawful purpose. Use a unique lowercase code.

Run `npm run search -- add-catalogue --code=<code> --name="<name>" --owner="<owner>" --purpose="<purpose>" --by="<operator>"`. Use `--json` when reading the result for further analysis.

Read CLAUDE.md first. Use the operator’s actual name for --by. Preserve unknowns. Report the result and any unresolved issue. Never send, publish or change a live website.
