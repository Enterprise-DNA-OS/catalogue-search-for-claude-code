# /relevance-check

Run expected searches and show every failed rank or missing result. A failed expectation is a business finding, not a script crash.

Run `npm run search -- relevance-check --catalogue=<code>`. Use `--json` when reading the result for further analysis.

Read CLAUDE.md first. Use the operator’s actual name for --by. Preserve unknowns. Report the result and any unresolved issue. Never send, publish or change a live website.
