# /add-task

Read open tasks and add the requested owner and due date.

Run `npm run search -- add-task --catalogue=<code> --title="<work>" --owner="<owner>" --due-on=YYYY-MM-DD --by="<operator>"`. Use `--json` when reading the result for further analysis.

Read CLAUDE.md first. Use the operator’s actual name for --by. Preserve unknowns. Report the result and any unresolved issue. Never send, publish or change a live website.
